# סיבובים וסדר בקובייה — פריזמה

יישומון חקר אינטראקטיבי לקוביית רוביק, בעיצוב Prisming / פריזמה.

## עיקרי הגרסה
- סיבוב ישיר של הפאות U, D, F, B, R, L והפעולות ההפוכות עם Prime (′).
- ערבוב אקראי וניסיון לסדר את הקובייה.
- מצב בניית רצף וחישוב הסדר שלו.
- מצב "הדגישו את החלקים שזזו": חלקים שנשארו במקומם הופכים כהים ואטומים, בדומה להמחשה ב-Wonderlattice.
- אות קבועה במרכז כל פאה לזיהוי U/D/F/B/R/L גם אחרי שינוי נקודת המבט.
- עזרה מפורטת בעברית על הסימונים, Prime, כיווני הפאות, מצבי העבודה והסדר של רצף.
- לוגו ואייקוני עזרה/איפוס מקוריים מספריית Prisma.
- Simpler Pro מצורף מקומית.

אפשר להעלות את התיקייה ישירות ל-GitHub Pages.
